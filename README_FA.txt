پروژه اندرویدی بازی «فرار از نئون»
سازنده بازی: پارسا خان محمدی

این پروژه، نسخه HTML بازی را داخل یک برنامه اندرویدی آفلاین (WebView) اجرا می‌کند.
این خروجی هنوز APK آماده نصب نیست؛ برای ساخت APK باید پروژه را در Android Studio باز و Build کنید.

مراحل ساخت APK:
1) Android Studio را روی رایانه نصب کنید.
2) از File > Open، پوشه NeonEscapeAndroid را انتخاب کنید.
3) صبر کنید Gradle Sync تمام شود. در صورت درخواست، Android SDK Platform 35 و Build Tools پیشنهادی را نصب کنید.
4) از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) را انتخاب کنید.
5) پس از پایان، روی Locate کلیک کنید. فایل معمولاً در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.
6) APK را به گوشی اندرویدی منتقل کنید و نصبش کنید. ممکن است لازم باشد اجازه نصب از همان منبع را در تنظیمات اندروید فعال کنید.

ویژگی‌ها:
- اجرای آفلاین؛ دسترسی اینترنت در برنامه درخواست نشده است.
- تمام‌صفحه و مناسب صفحه لمسی.
- حداقل نسخه اندروید تنظیم‌شده: Android 6.0 (API 23).
- نام سازنده در صفحه اصلی بازی: پارسا خان محمدی.

نکته:
پروژه ساخته شده، اما این محیط Android SDK/Gradle build را اجرا نکرده است؛ بنابراین APK نهایی هنوز تولید یا روی گوشی آزمایش نشده.
